# ONBOARDING (about 15 minutes)
1. The app: what it does, for whom, and the store(s) you are submitting to.
2. The project: the folder path, the framework (native iOS, native Android, Expo or React Native, other), and how to run it.
3. Money: what people buy, digital or physical or outside service, and how payment is implemented today.
4. Accounts: how people sign in, which third-party providers, whether deletion exists and where.
5. User content: what people can post, message, share, or see.
6. Devices: iPhone only or iPad too; orientations; Android form factors.
7. Listing: put screenshots and the listing text in /listing as files. Put review notes if you have them.
8. History: previous submissions and rejections, pasted into /memory/SUBMISSIONS.md.
Then write PROFILE.md and run the first audit for the target store.
