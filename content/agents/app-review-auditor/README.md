# The App Review Auditor: install in 15 minutes

## What you need
- A Claude account (Pro or Max) and Claude Code
- The project folder for your app, and your screenshots and listing text as files
- Nothing else. No API keys.

## Install
1. Unzip this folder somewhere you keep work.
2. Open a terminal in that folder and run `claude` (Claude Code). It reads CLAUDE.md automatically.
3. Say: "Run onboarding." The agent interviews you and fills /memory.
4. Say: "Audit for Apple" or "Audit for Google." The findings report lands in /reports in the same session.

## If you do not use Claude Code
Open PROJECT-INSTRUCTIONS.md and paste it into a Claude Project or ChatGPT custom instructions, and upload the /rules and /memory files. You lose the ability for the agent to open and change your project directly; you keep the audit and the plan.
