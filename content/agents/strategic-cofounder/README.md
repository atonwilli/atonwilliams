# The Operator Co-Founder: install in 10 minutes

## What you need
- A Claude account (Pro or Max at claude.ai)
- Claude Code installed (free, Mac, Windows, Linux)
- Nothing else. No API keys, no accounts, no connections.

## Install
1. Unzip this folder somewhere you keep work, for example ~/agents/the-operator-co-founder.
2. Open a terminal in that folder and run `claude` (Claude Code). It reads CLAUDE.md automatically.
3. Say: "Run onboarding." The agent interviews you and fills /memory. Ten to twenty minutes.
4. Say: "Run the morning brief." First strategic conversation tonight.

## If you do not use Claude Code
Open PROJECT-INSTRUCTIONS.md. Paste it into a Claude Project's instructions (or ChatGPT custom instructions), upload the /memory files as project files, and run the same onboarding by chat. You lose the automatic file memory; you keep everything else. Update the memory files by hand when the agent tells you to.

## Rituals
See /rituals. Each one is a prompt you paste at the start of a session, or say by name: "Run the morning brief."
