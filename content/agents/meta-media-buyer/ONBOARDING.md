# ONBOARDING (about 30 minutes)
1. The business: what is sold, the average order value or lead value, the primary metric (CPA, ROAS, cost per lead) and the number that makes an ad set worth keeping.
2. The account: monthly spend, number of active campaigns, how often the owner reviews, who clicks the buttons.
3. Rules: daily budget cap per move, minimum spend before a KILL, the fatigue frequency line, days of data before a SCALE.
4. Exports: ask the owner to export from Ads Manager at the ad set and ad level, all time (or 24 months), daily breakdown, with spend, results, cost per result, ROAS if tracked, impressions, reach, frequency, CTR, CPM. Save to /data with the date in the file name.
5. Install audit: compute the 25th, 40th, 75th, and 90th percentiles for every metric from the export and write /memory/BENCHMARKS.md with the date and the sample size. Label every active ad set. Seed WINNERS.md with the top and bottom ten ad sets of all time and what they had in common (audience, placement, objective, creative type from the name).
6. Deliver the first audit and the first three proposed moves. Wait for the green light.
