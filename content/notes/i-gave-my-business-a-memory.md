<p>For the first year I used AI tools the way most people do. Open a chat, explain the business again, get something generic, fix it by hand, close the tab, repeat tomorrow. The tool was smart. It was also a stranger every single time.</p>
<h2>The brain file</h2>
<p>The fix was one document. Who we are and who we serve. The words we use and the words we never use. How we make decisions. What a finished piece of work looks like. What has already been decided so it does not get re-argued. In the tools I use it is a file the AI reads before every session. In others it is a custom instructions box. The name does not matter. The habit does.</p>
<p>The first version was a page. It is longer now, and every line in it is something I used to type into a chat window at least twice a week.</p>
<h2>What changed</h2>
<p>Three things. The first draft of anything got usable, because the tool started from our rules instead of the average of everything online. Handoffs got easier, because a new person or a new tool could read the same file and be current in ten minutes. And the arguments stopped, because decisions were written down somewhere the whole operation, human and otherwise, could see.</p>
<h2>The maintenance rule</h2>
<p>A brain file rots if you let it. My rule is that whenever I catch myself explaining something to the AI for the second time, that explanation goes in the file before I finish the session. Whenever a decision changes, the file changes the same day. It is a living document with one owner, and the owner is me.</p>
<blockquote>Every business already has a brain. It is spread across the founder's head, four group chats, and a folder nobody opens. Writing it down is the whole trick.</blockquote>
